# Haven Clinic

**Haven** is a Java SaaS clinic/hospital system you can sell: warm landing page, optional login/register, one-click demo, and a full care workspace.

## Menus

Dashboard · Patients · Appointments · Doctors · Prescriptions · Billing · Rooms · Inventory · Reports · Settings

Stack: **Java 17 · Spring Boot 3 · Spring Security · Thymeleaf · JPA · H2**

## Run

```bash
.\.tools\maven\apache-maven-3.9.16\bin\mvn.cmd spring-boot:run
```

Open: [http://localhost:8088](http://localhost:8088)
